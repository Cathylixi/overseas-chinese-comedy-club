海外华语脱口秀俱乐部成立于 2026 年，致力于为海外华人提供一个讲述真实人生与移民故事的舞台。俱乐部坚持“内容为王，笑点辅助”，通过华语脱口秀连接不同城市、职业与人生经历的华人，让更多真实而鲜活的声音被听见。
